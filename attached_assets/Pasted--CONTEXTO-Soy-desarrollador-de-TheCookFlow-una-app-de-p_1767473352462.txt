Busca estos patrones:

# FORMATO DE RESPUESTA
Para cada archivo, dame:

**ARCHIVO:** nombre.tsx
**LÍNEA:** número de línea
**ANTES:** código actual
**DESPUÉS:** código con ASSETS
**IMPORT NECESARIO:** Sí/No

# CAMBIOS TÍPICOS
```typescript
// ANTES
<img src="/logos/logo.png" />

// DESPUÉS
import { ASSETS } from '@/lib/config/assets';
<img src={ASSETS.logos.main} />
```
```typescript
// ANTES
style={{ backgroundImage: 'url("/backgrounds/bg.png")' }}

// DESPUÉS
import { ASSETS } from '@/lib/config/assets';
style={{ backgroundImage: `url(${ASSETS.backgrounds.chalkboard})` }}
```
